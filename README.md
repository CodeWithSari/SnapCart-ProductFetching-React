SnapCart – React Redux App

SnapCart is a simple e-commerce application built with React.  
It fetches products from an API and uses Redux Toolkit to manage cart and wishlist state.

Features
- Product listing and product details page
- Cart and Wishlist using Redux Toolkit
- Auto move items from Wishlist to Cart
- Cart and Wishlist data stored in localStorage
- Responsive UI using Bootstrap and React Icons

Concepts Used
- React Hooks
- React Router
- Redux Toolkit (store, slice, reducer, payload)
- API integration
- LocalStorage persistence

Tech Stack
- React.js
- Redux Toolkit
- Bootstrap
- React Icons

Purpose

This project is created to practice Redux concepts and real-world state management in React.
